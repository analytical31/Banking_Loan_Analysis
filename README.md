# Bank Loan Approval Analysis
## Project Overview
The Bank Loan Approval Analysis project is an end-to-end data analytics solution developed using SQL, Python, and Power BI. The project focuses on analyzing customer loan applications, identifying approval trends, evaluating applicant risk, and generating business insights for banking institutions.
The dataset contains customer demographic information, income details, loan information, credit scores, and loan approval status. The project demonstrates the complete data analytics workflow from data storage and querying to visualization and dashboard development.


-<a href="https://github.com/analytical31/Banking_Loan_Analysis/blob/main/Bank_Loan_Dataset.csv"> Bank_Loan_Dataset</a> </br>


## Objectives</br>
Analyze customer loan applications.</br>
Identify factors affecting loan approvals.</br>
Evaluate customer creditworthiness.</br>
Track loan distribution across different loan types.</br>
Create interactive dashboards for decision-making.</br>
Generate actionable business insights.</br>
